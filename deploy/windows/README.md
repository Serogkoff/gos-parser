# Постоянный запуск на Windows 10/11

Пакет создаёт две фоновые задачи Планировщика Windows:

- `GosParser-Worker` — запускает `main.py`;
- `GosParser-Web` — запускает локальный сайт `web_app.py`.

Обе задачи запускаются при входе текущего пользователя, работают без открытых
окон PowerShell и автоматически перезапускаются через минуту после сбоя.
Повторный экземпляр одной задачи не запускается.

## До установки

1. Скопируйте или клонируйте проект на постоянное место.
2. Создайте `.venv`, установите `requirements.txt` и браузеры Playwright.
3. Перенесите `.env`, `.monitor_secret` и `news.db` отдельно — они не хранятся
   в Git.
4. Выполните полный тест проекта.

## Установка

Откройте обычный PowerShell в корне проекта и передайте точный Python из venv:

```powershell
Set-ExecutionPolicy -Scope Process Bypass

.\deploy\windows\install.ps1 `
    -PythonExe "C:\путь\к\.venv\Scripts\python.exe"
```

Администраторские права не нужны. Компьютер должен оставаться включённым,
пользователь — вошедшим в Windows, а переход в сон нужно отключить.

## Проверка

```powershell
.\deploy\windows\status.ps1
Get-Content .\runtime_logs\worker.log -Tail 40
Get-Content .\runtime_logs\web.log -Tail 40
```

Сайт доступен только на самом компьютере:

```text
http://127.0.0.1:5000
```

Логи автоматически ограничиваются десятью мегабайтами на файл. Хранятся семь
предыдущих частей каждого журнала. `main.py` уже создаёт проверенную ежедневную
копию SQLite и оставляет семь последних копий в `backups`.

## Безопасное удалённое обновление

После того как новая версия проверена на основном компьютере и отправлена в
GitHub, на офисном компьютере выполните:

```powershell
.\deploy\windows\update.ps1 `
    -PythonExe "C:\путь\к\.venv\Scripts\python.exe"
```

Скрипт отказывается работать с изменённым Git-деревом, получает `origin/main`,
проверяет fast-forward и запускает полный набор тестов во временной копии.
Только после успешных тестов он останавливает задачи, создаёт ручную копию
SQLite, применяет обновление и снова запускает worker и сайт. Если изменился
`requirements.txt`, автоматическое обновление останавливается и просит сначала
обновить зависимости вручную.

Для доступа из дома используйте только разрешённый офисной политикой VPN или
защищённую сеть наподобие Tailscale вместе с RDP. Не публикуйте порты `3389` и
`5000` в интернете.

## Остановка и удаление автозапуска

```powershell
Stop-ScheduledTask -TaskName "GosParser-Worker", "GosParser-Web"
.\deploy\windows\uninstall.ps1
```

Удаление заданий не затрагивает проект, базу, секреты, резервные копии и логи.
