# Развёртывание на Ubuntu 22.04/24.04

Рекомендуемая схема: основной сервер в России, а только Киодо обращается к
голландскому SOCKS5. Это сохраняет доступ к российским государственным сайтам.

## До установки

1. Создайте резервную копию `news.db`.
2. Скопируйте проект на сервер, например в `/opt/gos-parser`.
3. Если нужна прежняя история и пользователи, отдельно скопируйте `news.db` —
   этот файл намеренно не хранится в Git.
4. Откройте на сервере порты 22, 80 и позднее 443. Порт Flask 5000 открывать
   наружу не нужно.

## Установка

Из корня проекта:

```bash
chmod +x deploy/install_ubuntu.sh deploy/check_server.sh
sudo ./deploy/install_ubuntu.sh example.com
```

Если домена пока нет, вместо него передайте `_`:

```bash
sudo ./deploy/install_ubuntu.sh _
```

Установщик создаёт системного пользователя `gosparser`, виртуальное окружение,
Chromium для Playwright, две службы systemd и конфигурацию Nginx. Настоящие
секреты он не записывает в репозиторий.

Откройте настройки:

```bash
sudo nano /etc/gos-parser.env
```

Укажите SOCKS5 Киодо. Если прокси работает на другом сервере, используйте его
доступный IP или домен. Если SOCKS5 поднят на этом же VPS — `127.0.0.1`.

После сохранения:

```bash
sudo systemctl start gos-parser-worker gos-parser-web nginx
sudo ./deploy/check_server.sh
```

Логи:

```bash
sudo journalctl -u gos-parser-worker -f
sudo journalctl -u gos-parser-web -f
```

Перезапуск после обновления кода:

```bash
sudo systemctl restart gos-parser-worker gos-parser-web
```

Службы автоматически запускаются после перезагрузки и восстанавливаются после
падения. Сайт работает через Unix-сокет и не выставляет Gunicorn напрямую в
интернет.

## HTTPS

Сначала привяжите домен к IP сервера и убедитесь, что сайт открывается по HTTP.
На следующем этапе можно установить Certbot и выпустить сертификат. После этого
в `/etc/gos-parser.env` переключите `MONITOR_HTTPS=1` и перезапустите веб-службу.
