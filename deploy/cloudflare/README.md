# Постоянный адрес news-monitor.ru

`news-monitor-proxy.js` передаёт запросы с `news-monitor.ru` в работающий
Tailscale Funnel, не отправляя браузеру редирект. Поэтому адресная строка
остаётся на домене проекта.

Перед подключением Worker необходимо отключить созданное ранее правило
`Временный переход на парсер`. Затем код из `news-monitor-proxy.js`
публикуется как Cloudflare Worker и назначается на Custom Domain
`news-monitor.ru`.

Tailscale Funnel на рабочем компьютере должен оставаться включённым. Порт
`5000` открывать в Windows или на роутере не требуется.
